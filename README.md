## About the Project

This website was built for **Tonny Omi Movers** to establish a professional online presence, attract new clients, and make it easy for customers to request a quote or get in touch. The site covers all the company's core services and includes clear pricing based on the Nairobi moving market.

---

## Pages

### 1. Home Page

- Bold hero section with headline and call to action
- Brief company introduction
- Why Choose Us section highlighting key strengths

### 2. Services Page

- Four service cards with icons and descriptions
- Pricing table based on typical Nairobi mover rates

### 3. About Page

- Company story and values
- Profile of founder Anthony Peter
- Company mission and customer-first approach

### 4. Get a Quote Page

- Clean quote request form
- Fields for move details, service type, and preferred date
- Thank you message on submission

### 5. Contact Page

- Phone number and email
- WhatsApp chat button
- Social media links
- Google Maps embed placeholder
- Short contact form

## Features

- Fully responsive across all devices
- Sticky navigation bar with hamburger menu on mobile
- Smooth scroll between sections
- Floating WhatsApp button on every page
- Quote request form with thank you confirmation
- Social media links to Facebook and Instagram
- Back to top button
- Testimonials section
- Pricing table

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling, animations, and responsive media queries
- **JavaScript** — Hamburger menu, smooth scroll, form handling
- **Google Fonts** — Playfair Display for headings, DM Sans for body text
- No frameworks or external libraries required

## Getting Started

### Prerequisites

- VS Code
- Live Server extension installed in VS Code

### Run Locally

1. Download or clone the project
2. Open the folder in VS Code
3. Right click on `index.html`
4. Click **Open with Live Server**
5. The site opens at `http://127.0.0.1:5500`
